# پچ ۶۰-ب — هات‌فیکس لاگین (?denied=1)

> تاریخ: 2026-11-22 · علت: ستون `is_active` در جدول `admin_operator_profiles` وجود نداشت
> (فقط روی `staff_members` بود) — select کاملِ پروکسی خطا می‌داد و پروکسی پروفایل را
> «ناموجود» می‌پنداشت → همه به `?denied=1` می‌خوردند. تیک‌های صفحهٔ دسترسی‌ها سالم بودند.

## مرحلهٔ ۱ — SQL (خودش کافی است؛ بدون دیپلوی جدید لاگین باز می‌شود)

Supabase → SQL Editor → کل `patch-60-modules-access.sql` (نسخهٔ جدید داخل همین zip)
→ Run. این دستور با `if not exists` هر دو ستون (`allowed_paths` و `is_active`) را
تضمین می‌کند — اجرای دوباره بی‌ضرر است.

در خروجی کنترل باید دو سطر ببینی: `allowed_paths` و `is_active`.
بلافاصله تست کن: با c2 وارد شو — نباید دیگر denied ببینی.
